# Security

Treat this as early-stage software, not a safety-critical monitoring or alerting
system. Use an unprivileged desktop account. Cache data and previews may reveal
machine names, loaded models, workload names and resource usage.

Do not post credentials, private configuration, snapshots or exploitable details
in public issues. Contact the repository owner privately for security reports;
use GitHub private vulnerability reporting if enabled on the published repository.
No external reporting endpoint or response-time promise is currently established.

The display application reads local telemetry and writes pixels to the selected
USB serial port. It has no remote execution, firmware-flashing or collector
credential-management functionality. Existing collectors retain their separate
access controls and authorisation requirements.
