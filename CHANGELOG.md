# Changelog

## 0.2.0 — local candidate, 19 November 2026

- Same-user next/previous/pin/auto controls without global keyboard capture.
- Sustained-temperature, battery, storage, freshness and ZFS warnings.
- Advisory RAM/VRAM labels distinguish allocation from inference activity.
- Observed build-stage duration, optional real inference counters and explicit
  not-measured labels when a source supplies no activity counter.
- Optional timezone-aware night dimming and systemd user-service example.
- Regression tests for warning timing, pin behaviour and private control sockets.

## 0.1.0 — local candidate, 19 November 2026

- Portrait laptop dashboard with CPU/network histories and OS battery runtime.
- Cache-fed AI-workstation and Proxmox pages with visible observation age.
- Atomic private snapshot publisher; last-good samples survive probe failures.
- Configurable names, cache sources, timing, port, font and portrait rotation.
- USB-free page previews, limited reconnect retries and a 50% brightness ceiling.
- GPL-3.0-or-later provenance, package metadata and offline regression tests.

Original two-page implementation was confirmed on a physical TURMO display.
The configurable package and Proxmox integration require their own acceptance.
No public release or repository publication is asserted by this file.
